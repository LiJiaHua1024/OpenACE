# Known Issues / Escape-Hatch Register

- Media-bin drag/drop placement is functionally correct, including Alt fine placement, but the cyan insertion indicator can disappear on one narrow Alt lower-diagonal native HTML5 drag path despite dragleave grace-timer hardening. Direct steady-position drags and normal placements show correct feedback; documented after three browser reproduction/fix attempts rather than blocking the workflow.
- Web playback media now preloads/decodes offline and realistic post-interaction first playback is verified below 20ms audio-clock lag, but a direct cold press of play as the very first browser gesture can still incur the host Chrome/audio-device startup cost (about 2 seconds in this sandbox). This is an environment/browser output initialization limitation, not a decode-cache miss.
- True ACE-style weighted voice mixing is architecturally blocked by current upstream SoulX-Singer: inference accepts only the first prompt segment and conditions on prompt waveform/mel features, not an exposed speaker embedding or weighted multi-prompt interface. OpenACE intentionally does not fake mixing by blending raw reference audio.

## Critical validation gaps

- Real GPU inference has not been run in this CPU-only cloud sandbox. `scripts/verify_local_gpu.py` is the required acceptance gate on a 12GB NVIDIA machine.
- Real SoulX-Singer/ACE-Step output quality, exact preprocess artifacts, and ACE-Step repaint/complete semantics still need physical GPU logs and listening validation.

## Current product gaps after the independent browser QA fix round

- Tempo maps now import/export, drive timing correctly across MIDI/LRC/USTX/SVP/VPR/rendering/playback, and have browser-verified visual drag/numeric/delete/copy/paste/undo support including step/linear ramp transitions. Host-native ramp roundtrip metadata remains absent.

- Pitch automation affects SoulX target F0; Dynamic, Air, Energy, Tension, and Falsetto automation are applied as explicitly labeled post-render DSP. Breath events now overlay real donor aspiration extracted from reference/rendered audio and are explicitly labeled post-render DSP, but if no suitable real donor noise exists they honestly no-op; per-breath intensity and soft/natural/strong donor spectral shaping are implemented, but true neural breath conditioning remains absent.
- Piano roll now has marquee/multi-select/copy-paste/duplicate/quantize/context menu/velocity lane, per-note vibrato editing, browser-verified freehand user-pitch brush, pitch eraser, and per-note pitch anchors, truthful vowel-continuation note splitting, cross-track clipboard regression verification, and dense 3000-note 60FPS playback/scroll proof at 1400×900@2x. ACE-style fixed brush is implemented as a truthful fresh-rendered-F0/deterministic-target approximation because upstream SoulX exposes no pre-render neural AI-pitch curve; exact hidden-AI-pitch parity remains absent. The dedicated pitch eraser removes continuous user pitch and per-note anchors. Direct vibrato creation/reshaping and depth/phase/frequency canvas handles are implemented, but ACE's attack/release envelope circles, marquee selection/deletion of multiple vibratos, modulation tool, and unvoiced-pitch semantics remain absent.
- Arrangement now uses decoded waveform peaks and supports independent audio-clip/grouped-note dragging, edge trim, split-at-cursor, linear fade endpoints, clip gain, and automatic equal-power crossfades, clip copy/paste/duplicate/delete, and track duplicate/reorder/color/delete context operations, plus project/media pinning/tag/folder organization, but still lacks deeper smart media-library collections.
- Repaint arrangement-to-source integration is now browser/quantitatively verified in fixture mode, but the underlying real ACE-Step repaint musical quality and boundary masking still require physical GPU validation.
- MP4 export now burns phrase-grouped `\kf` karaoke highlighting with collision-aware multi-track lanes, customizable typography/position/effects, and matches audio duration. Fontconfig may substitute unavailable lyric fonts, and advanced audio-reactive scene graphics remain absent. On Linux hosts without CJK fonts, Chinese glyphs may render as tofu even though project/export text is valid UTF-8.
- `.ustx` now opens, synthesizes/plays with a real temporary Eugene/友人 voicebank, and survives Ctrl+S host-save/reimport roundtrip validation in official Linux OpenUtau 0.1.576; broader singer-matrix validation remains absent. Per-clip gain is not representable in UWavePart and is therefore not exported/faked. Browser single-file USTX upload cannot access sibling audio files beside the original project, although secure zip packages with bundled media are supported; external unbundled relative wave media may remain unresolved unless paths are reachable; `.svp` now opens in real OpenUtau 0.1.576 through its SVP importer with correct notes/lyrics/vibrato/pitch/loudness, but still needs real Synthesizer V validation; OpenUtau does not preserve mixer/color metadata; `.vpr` remains a structural implementation and must be opened in actual VOCALOID.
- Cantonese is validated through pycantonese/Jyutping and exact SoulX `yue_*` phones, but polyphonic disambiguation and GPU listening remain open; Japanese score rendering is unavailable because the current SoulX phone set has no Japanese inventory. Unsupported input correctly errors instead of silently becoming “la”.
- Render jobs persist across backend restart and recoverable interrupted jobs are automatically requeued; very extreme sparse-transient masters can still fail loudness validation loudly instead of being silently exported below spec.
- Local faster-whisper word-timestamp lyrics are integrated into audio import and verified on a real vocal. ASR can still misrecognize sung words, monophonic pitch extraction can fragment or merge syllables, and notes that cannot be aligned remain blank for user correction. Dedicated score lyric correction and SVC timed-lyric display/editing are implemented, but phoneme-level correction for converted audio and multi-language visual validation remain absent.
